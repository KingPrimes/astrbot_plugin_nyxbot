# =============================================================================
# AstrBot 插件依赖清单
#
# AstrBot >= 4.29 安装插件依赖时会附加一份「核心依赖版本保护」约束文件
# （`pip install -r requirements.txt -c <临时constraints.txt>`），其中每一项
# 都是 Core 当前**已安装**的精确版本，例如 aiohttp==3.14.5。
#
# 因此规则是：
#   1) 与 AstrBot Core 共享的包 —— 只能写 `>=` 下限，绝不能写 `==` 精确版本。
#      写精确版本会被判定为「核心依赖降级」并直接中止安装：
#      DependencyConflictError: aiohttp==3.13.5 vs (constraint) aiohttp==3.14.5
#   2) 插件私有的包 —— Core 不直接依赖，可以钉死版本以保证可复现。
#
# 共享依赖清单（对应 AstrBot pyproject.toml 的 dependencies）：
#   aiohttp / httpx / apscheduler / pydantic / pillow
#
# ⚠️ 不要再用 `uv pip compile pyproject.toml --no-deps -o requirements.txt`
#    重新生成本文件 —— 它会把下面所有包重新钉成 `==` 精确版本，冲突会复发。
# =============================================================================
